# AGENTS.md entry point

## Purpose

`claude-team-skills/templates/AGENTS.md` lets coding agents other than Claude Code follow CTS. It is
generated by `scripts/build-agents-md.py`: the rules are fixed text and the specialist table is built
from each skill's frontmatter.

## Requirements

### Requirement: track selection

The file SHALL tell the agent to pick Quick, Standard or Full for every request, and to read
`skills/orchestrator/SKILL.md` first on Standard and Full.

#### Scenario: never-Quick areas

- GIVEN a request that touches auth, payments, data migrations, or shipping
- WHEN the agent picks a track
- THEN it picks Standard or Full

### Requirement: opening questions

On Standard and Full, the file SHALL tell the agent to open with the UNDERSTAND questions (what,
where, how big), to skip any the user has already answered, and to state the track and why before
offering options or writing code.

#### Scenario: plain feature request

- GIVEN the request "I need to add user authentication to my app"
- WHEN the agent replies
- THEN the reply asks the unanswered questions and names the track
- AND it contains no options and no code

Whether GitHub Copilot CLI follows this rule is (unverified): it was added on 13 November 2026 and
not yet re-tested there.

### Requirement: user gates

On Standard and Full, the file SHALL require the user to pick a BRAINSTORM option before PLAN and to
confirm the PLAN before EXECUTE.

### Requirement: ship refusal names VERIFY

The file SHALL tell the agent to refuse a ship, push or deploy with no passing VERIFY entry, to say
that VERIFY has not passed, and to offer to run it.

### Requirement: generated, never stale

`build-agents-md.py --check` SHALL exit 1 when the committed file differs from the generated one. CI
runs it on every push.
