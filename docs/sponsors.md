# GitHub Sponsors

Setup checklist, profile text and tiers for sponsoring CTS. Milestone: Sponsors on by 27 November 2026
(day 14 of the [monetisation plan](monetisation-plan.md)).

Sponsorship and the paid services in [CTS for teams](for-teams.md) are separate. Sponsors support
maintenance; they do not buy hours. No tier includes setup, calls or guaranteed response times, so a
sponsorship never undercuts a service quote.

## Setup checklist

Only you can do these steps; they need your identity, bank and tax details.

- [ ] Confirm Morocco is in the supported list under "View country and region list" on
      [github.com/sponsors](https://github.com/sponsors). It was added in July 2022, but re-check before
      applying.
- [ ] Turn on two-factor authentication for the GitHub account, if it is not on already.
- [ ] Join at [github.com/sponsors](https://github.com/sponsors) → "Get sponsored" → choose the
      personal account `rhorba`.
- [ ] Payouts: connect a Stripe account and the bank account that receives the money. Have your ID
      and IBAN or account details ready.
- [ ] Tax form: GitHub asks for a W-8BEN as a non-US individual. Fill it in with your details as
      they appear on your ID.
- [ ] Paste the profile text and create the three tiers below.
- [ ] Submit for review. GitHub reviews new profiles before they go live; the wait varies.
- [ ] After approval, check that the "Sponsor" button appears on the repository (it is driven by
      `.github/FUNDING.yml`) and that the README link opens your profile.
- [ ] Ask the accountant about sponsorship income in the same conversation as service invoicing
      (open question 3 in the plan).

Until the profile is approved, the README sponsor link leads to a page that does not exist yet.
Merge this branch after approval, or accept a few days of a dead link.

## Profile text

**Short bio**

> I build CTS, a free Claude Code plugin that makes AI coding work in phases and blocks `git push`
> until tests and coverage are logged.

**Introduction**

> CTS (Claude Team Skills) gives Claude Code a team of 23 specialist skills and one rule it cannot talk its
> way out of: nothing ships until verification has passed. The push gate is a hook, not a prompt, and
> it works as a plain git pre-push hook too.
>
> CTS is MIT-licensed and stays that way. Sponsorship pays for the work that keeps it honest:
> running the evals that check the plugin still holds its rules, fixing what they catch, and keeping
> up with Claude Code releases.
>
> If you want CTS set up for your team, that is a separate, fixed-price service:
> see [CTS for teams](https://github.com/rhorba/CTS/blob/main/docs/for-teams.md).
